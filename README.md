# AI Agents — інтерактивний посібник

Простий інтерактивний вебпроєкт, який пояснює концепцію **AI-агентів**, їх основні компоненти, типи та типовий цикл роботи.

Проєкт також містить невеликий **симулятор AI-агента**, реалізований на JavaScript. Він демонструє, як агент може отримати задану користувачем мету та послідовно пройти етапи спостереження, аналізу, планування, вибору інструментів, виконання дій та оцінювання результату.

## Можливості

* Вступ до концепції AI-агентів
* Пояснення основних можливостей агента:

  * сприйняття інформації;
  * міркування;
  * планування цілей;
  * використання інструментів;
  * пам’ять;
  * цикл зворотного зв’язку.
* Огляд різних типів AI-агентів
* Візуалізація циклу роботи агента: **Спостереження → Аналіз → Планування → Дія → Оцінювання**
* Інтерактивний локальний симулятор
* Адаптивний темний інтерфейс
* Повністю працює у браузері
* Не потребує бекенду або зовнішніх залежностей

## Запуск локально

Клонувати репозиторій:

```bash
git clone https://github.com/ViktoriaZaretska/day-2.git
```

Перейти до каталогу проєкту:

```bash
cd day-2
```

Після цього відкрити файл `index.html` у браузері.

Також можна запустити простий локальний сервер за допомогою Python:

```bash
python -m http.server 8000
```

Після запуску відкрити у браузері:

```text
http://localhost:8000
```

## Інтерактивний симулятор

У розділі **Interactive Agent Simulator**:

1. Оберіть тип агента.
2. Введіть мету.
3. Натисніть **Run Agent**.
4. Спостерігайте за етапами роботи агента у вбудованій консолі.

Поточний симулятор має навчальний характер і працює локально на JavaScript. Він не підключається до зовнішньої AI-моделі.
